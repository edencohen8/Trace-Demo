# TRACE evidence package — case_003

This folder contains simulated raw data from a mostly working sensor system. It does not contain an answer key.

## Files

- `raw/sniffer.csv` — selected messages from the simulated bus (timestamps are UTC).
- `raw/*.txt` — component logs (each system has its own log style).
- `raw/operator_diary.xlsx` — operator notes, with approximate local times.
- `capture_manifest.json` — a description of the exported fields, message types and clocks.
