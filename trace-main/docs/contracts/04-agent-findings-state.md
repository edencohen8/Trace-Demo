## 3. Chat Event Stream for UI Console (Lane 5)

Lane 3 streams JSON events via Server-Sent Events (SSE) or WebSocket:
- `event: thinking` -> `{ phase: "fact_finding" | "hypothesizing" | "evaluating", thought: "..." }`
- `event: tool_call` -> `{ tool: "delegate_investigation", args: {...} }`
- `event: tool_result` -> `{ tool: "delegate_investigation", summary: "..." }`
- `event: blackboard_update` -> `InvestigationBlackboardState` (see §4)
- `event: finding` -> Full `Finding` JSON object.
- `event: done` -> Final investigation summary report.
