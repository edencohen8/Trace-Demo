# הפעלת דמו T015I

1. מתוך `trace-main`, הפעילו `npm run check:ai` כדי לבדוק את הגדרות הספק.
2. הפעילו `npm run dev` ופתחו `http://127.0.0.1:5180/?case=case_005`.
3. בחרו **כשל בזיהוי מטרה T015I**. האות האחרונה היא I לטינית.
4. שאלו: **למה מטרה T015I לא התגלתה באזור שציינתי?**
5. במהלך החקירה פתחו אסמכתא מתוך ממצא. מעבר ידני בציר הזמן נשמר בזמן עדכוני הרקע.
6. בסיום אפשר לפתוח את מקורות הממצא, את פירוט הממצאים ואת מהלך הבדיקה.

אסמכתא בשם **חישוב אזור** פותחת את ספירות הגילויים, כיסוי ההקלטה, מצב הסריקה
והחסימה, ואת הקישורים לרשומות שעליהן החישוב מבוסס. היא אינה שורת לוג מומצאת.

לצילום הסרטון אפשר להאיץ את זמן ההמתנה. ההתקדמות מתעדכנת לפי בדיקות אמיתיות;
אין רצף שלבים שמופעל לפי טיימר. משך החקירה משתנה בין הרצות.

שאלות המשך לבדיקה:

- האם המפעיל באמת ביטל את החסימה?
- למה הממשק הציג שאין חסימה?
- מה בדיוק לא התאים בין גרסאות התוכנה?
- מה השתנה לפני שהמטרה כן התגלתה?
- תן לי סיכום קצר למפעיל.

הסשן נשמר לכל תיק בנפרד. רענון טוען תשובות שהושלמו ואת מהלך הבדיקה שלהן.
כדי להתחיל חקירה עצמאית חדשה, השתמשו בכפתור ניקוי השיחה. המסקנות שאושרו בנפרד נשמרות.

## שחזור ובדיקות

```bash
npm run generate:radar
npm run test:radar
npm run typecheck
npm test
npm run build
npm run qa:radar -- all /tmp/trace-radar-qa
```

בדיקות המודל משתמשות בספק ובמודל המוגדרים ב־`.env`. אין להדביק מפתחות בצ׳אט.
הגנרטור אינו חלק מהסוכן בזמן ריצה. הווריאנטים נבנים בתיקיות זמניות, ללא תווית
הווריאנט או התשובה המצופה בקונטקסט של החוקר.

הקבצים הם ראיות סינתטיות. מיקום המטרה הוא דיווח מתיאום התרגיל עם אי־ודאות.
התאמה מרחבית של גילוי במעבר החוזר אינה אישור עצמאי לזהות המטרה.
